# NextGenFiler

Windows標準のエクスプローラーに代わる、高速・多機能なデスクトップファイラーアプリです。
Python と PySide6 で構築されており、ローカルファイルの操作だけでなく、SFTP や共有フォルダ（SMB）への接続・ファイル暗号化機能などを備えています。

---

## 主な機能
* **快適なファイル操作**: コピー、移動、リネーム、削除などの基本操作
* **ネットワーク接続**: SFTP および SMB（Windows共有フォルダ）への接続サポート
* **セキュリティ機能**: ファイルの暗号化・復号ツール搭載
* **プレビュー機能**: PDF や Web コンテンツの閲覧サポート

---

## 使い方（配布版 ZIP を受け取った方向け）

Python のインストールは不要です。以下の手順ですぐに使い始められます。

1. **ZIPファイルを解凍する**
   ダウンロードした ZIP ファイルを右クリックし、「すべて展開」で好きな場所（`ドキュメント` フォルダなど）に解凍します。
2. **初回セットアップ＆起動**
   フォルダ内の **`NextGenFiler.bat`** をダブルクリックします。
   * **初回のみ**：黒い画面が開き、必要な部品の自動ダウンロードが始まります（インターネット接続が必要です。完了まで数分かかります）。
   * **2回目以降**：黒い画面は出ず、一瞬でアプリが起動します。
3. **便利なショートカットの作成（おすすめ）**
   `NextGenFiler.bat` を右クリック ＞「その他のオプションを表示」＞「送る」＞「デスクトップ（ショートカットを作成）」を選ぶと、デスクトップからいつでも起動できます。

## 開発者向けセットアップ（GitHub からクローンする場合）

1. リポジトリをクローンします。
   ```bash
   git clone https://github.com/KotaOkano/next-gen-filer.git
   cd next-gen-filer
   ```
2. 仮想環境を作成し、依存ライブラリをインストールします。
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. アプリを起動します。
   ```bash
   python main.py
   ```
